# План: одностраничный сайт компании по внедрению ИИ в клиники

## Технические требования (уже зафиксированы)

- **Файл:** один [index.html](index.html) в корне проекта.
- **Зависимости:** никаких — только встроенные CSS и при необходимости минимальный inline JS (если понадобится плавная прокрутка или меню).
- **Адаптив:** mobile-first, брейкпоинты для телефонов и десктопа (например, 480px, 768px).
- **Цвета:** тёмный фон (например, #0d0d12, #1a1a24), градиент с фиолетовыми оттенками (#6b21a8, #7c3aed, #a78bfa), акценты — фиолетовый для кнопок и ссылок.

## Структура страницы

1. **Герой (Hero)**
  - Название компании (придумать, например «МедИИ» или «AI Clinic Pro»).  
  - Заголовок (один слоган про внедрение ИИ в клиники).  
  - Краткое описание (1–2 предложения).  
  - Всё в одной секции с градиентным фоном.
2. **О себе (About)**
  - 2–3 абзаца: чем занимается компания, опыт, преимущества, технологии.  
  - Текст придумать под тематику «внедрение ИИ в клиники» (диагностика, автоматизация, аналитика).
3. **Контакты**
  - Email (placeholder, например `hello@medai.ru`).  
  - Ссылка на Telegram (иконка/кнопка, placeholder `t.me/...`).

## Дизайн и вёрстка

- **Градиентный фон:** тёмный градиент (например, сверху/по диагонали) с фиолетовыми пятнами или мягким переходом в фиолетовый.
- **Типографика:** системный стек шрифтов (например, `system-ui, -apple-system, sans-serif`) без подключения внешних шрифтов.
- **Секции:** семантические теги `<header>`, `<main>`, `<section>`, `<footer>`; у каждой секции свой блок с отступами и max-width для читаемости.
- **Минимализм:** много «воздуха», простые карточки/блоки без перегруза, акцент только на кнопках и ссылках (фиолетовый).

## Адаптив

- Базовые стили — для мобильных (узкий экран).  
- Медиа-запросы: увеличение отступов и размера шрифтов на `min-width: 768px` (и при необходимости 1024px).  
- Меню не требуется (одна страница, якоря при желании можно добавить для плавного скролла по секциям).

## Контент (на русском)

- Название компании, слоган и описание в Hero — придумать под «внедрение ИИ в клиники».  
- Блок «О себе» — 2–3 абзаца с ключевыми темами: ИИ в медицине, автоматизация, аналитика, опыт внедрений.  
- Контакты: один email и одна ссылка на Telegram с плейсхолдерами; реальные значения пользователь подставит сам.

## Итоговая структура index.html

- Верхняя часть: `<meta charset="utf-8">`, viewport, заголовок `<title>`.  
- Один блок `<style>` в `<head>`: сброс отступов/полей, переменные цветов (тёмный фон, фиолетовые акценты, градиент), стили секций, типографика, кнопки/ссылки, медиа-запросы.  
- Тело: Hero → О себе → Контакты; в контактах — `mailto:` и ссылка на Telegram.  
- Без скриптов из CDN; при необходимости — минимальный inline JS только для плавного скролла по якорям.

После согласования плана можно перейти к написанию единственного файла [index.html](index.html) с полной разметкой и стилями под эти требования.
