# MedAI — лендинг внедрения ИИ в клиники

Публичный репозиторий лендинга компании MedAI (MedAI Nexus).

## Содержимое

- `index.html`, `index2.html` — варианты главной страницы
- `medical-ai-landing/` — шаблон и ассеты лендинга

## Локальная разработка

Откройте `index.html` или `index2.html` в браузере. Секреты и переменные окружения храните в `.env` (см. `.env.example`); они не коммитятся.
